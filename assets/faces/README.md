# Fețe foto (opțional)

Pune aici două fișiere JPG, fotografii **frontale**, față în centru, cap întreg vizibil, lumină uniformă:

- `trump.jpg`
- `putin.jpg`

Jocul le proiectează automat pe capul 3D și ascunde ochii/nasul/gura procedurale. Fără fișiere, rămâne capul stilizat.
Ajustare decupaj: `face.crop` în `js/chars.js` (`cx`, `cy` = centrul feței, `w`, `h` = fracțiune din imagine).

Folosește doar imagini pentru care ai drept de utilizare (licența verificată pe pagina fișierului sursă). Nimic din acest repo nu descarcă fotografii.
